# ROCK PAPER SCISSORS
## Description
Indeed, It's Rock Paper Scissors

## SYSTEM REQUIREMENTS
### Minimum System Requirements:
* CPU: Intel Pentium 4 6xx series or AMD Sempron 2800+ E6
* GPU: Nvidia 6150 or AMD equivalent
* RAM: 2GB
* MONITOR RESOLUTION: 1280 x 720
* OS: WINDOWS 10 64-bit
* STORAGE: 100MB	
* SOUND: yes
* PERIPHERAL: Keyboard


### Recommended System Requirements:
* CPU: Ryzen 9 9950X3D2 or Intel Core Ultra 9 285K
* GPU: NVIDIA GeForce RTX 5090 or AMD equivalent
* RAM: 64GB+ ECC
* MONITOR RESOLUTION: 7680 x 2160
* OS: WINDOWS 10 64-bit or newer
* STORAGE: 100MB Gen 5 NVMe SSD
* SOUND: Similar to an Opel Astra
* PERIPHERAL: 75% Keyboard, Good gaming chair

## Features:
* 3 whole game modes:
  * T3P: First to 3 points
  * T5P?: First to 5 points
  * Free Play: As the name says
* Intuitive and User-friendly UI
* Statistics: The game saves your results (and keeps it)
* ...and much more...
