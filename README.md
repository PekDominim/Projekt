# ROCK PAPER SCISSORS
## Description
Indeed, It's Rock Paper Scissors

## SYSTEM REQUIREMENTS
### Minimum System Requirements:
* CPU: Intel Pentium 4 E6 or AMD Sempron 2800+ E6
* GPU: Nvidia 6150 or AMD equivalent
* RAM: 2GB
* MONITOR RESOLUTION: 1280 x 720
* OS: WINDOWS 10 64-bit
* STORAGE: 100MB	
* SOUND: yes
* PHERIPHERIAL: Keyboard


### Recommended System Requirements:
* CPU: Ryzen 9 9950X3D2 or Intel Core Ultra 9 285K
* GPU: NVIDIA GeForce RTX 5090 or AMD equivalent
* RAM: 64GB+ ECC
* MONITOR RESOLUTION: 7680 x 2160
* OS: WINDOWS 10 64-bit or better
* STORAGE: 100MB Gen 5 NVMe SSD
* SOUND: Similar to an Opel Astra
* PHERIPHERIAL: 75% Keyboard, Good gaming chair

## Features:
* 3 whole gamemodes: T3P T5P and Free Play
* Intuitive and User friendly UI
* ...and much more...
